privacy policy

What this app collects

Nothing. World Scores has no account system, no login, no analytics, and no advertising. It does not collect, store, or transmit any personal data about you.

What it does

On launch, the app fetches public scoreboard data directly from ESPN's public `site.api.espn.com` endpoints and displays it. That request goes from your device to ESPN; no server operated by World Scores sits in between, and no data about you or your device is sent as part of it beyond what any normal HTTP request includes (e.g. your IP address, which ESPN's servers see the same way they would for any visitor).

Third parties

The only third party involved is ESPN, whose public API supplies the scores shown in the app. World Scores has no relationship with ESPN beyond reading this public data, and is not affiliated with or endorsed by ESPN.

Changes

If this ever changes — for example, if a future version adds any feature that collects data — this page will be updated to say so before that version ships.

Questions about this policy: see the app page for contact details.
